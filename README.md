# Statistical and Machine Learning Based Student Placement Prediction

This project explores the relationship between students' academic performance, technical skills, and campus placement outcomes using statistical analysis and machine learning techniques.

Using the Indian Student Placement Dataset (2025), the project performs exploratory data analysis, hypothesis testing, feature analysis, and predictive modeling to identify key factors associated with student placements.

### Key Features
- Exploratory Data Analysis (EDA) and data visualization.
- Statistical hypothesis testing using Welch's t-test, Chi-square test, and ANOVA.
- Feature correlation and effect-size analysis.
- Data preprocessing, encoding, and feature scaling.
- Placement prediction using:
  - Logistic Regression
  - Decision Tree Classifier
  - Random Forest Classifier
- Hyperparameter tuning using GridSearchCV.
- Model evaluation using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
- Individual student placement prediction.

### Tech Stack
Python | Pandas | NumPy | Scikit-learn | SciPy | Matplotlib | Seaborn

### Objective
To investigate the academic and skill-based factors associated with student placement and compare statistical and machine learning approaches for placement prediction.

**Note:** The dataset contains a deterministic placement-labeling rule. The reported perfect tree-based model scores reflect this synthetic labeling pattern and should not be interpreted as real-world placement accuracy.
